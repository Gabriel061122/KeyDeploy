# KeyDeploy

**De las necesidades de tu aplicación a una propuesta cloud clara.**

## Presentación

KeyDeploy es un proyecto académico que ayuda a convertir la descripción de una aplicación en una propuesta de infraestructura en la nube. Está pensado para que una persona pueda entender las opciones disponibles y sus costes sin tener que conocer de antemano los distintos servicios cloud.

## Problema y objetivo

Elegir los recursos adecuados para una aplicación puede resultar complicado: hay muchas opciones y es difícil anticipar cuánto costarán. KeyDeploy busca hacer ese proceso más accesible, ofreciendo propuestas comprensibles y presupuestos estimados que ayuden a tomar una decisión informada.

## ¿A quién va dirigido?

A personas, equipos y pequeños proyectos que quieren poner una aplicación en marcha, pero necesitan orientación para decidir qué infraestructura podría ajustarse a sus necesidades y a su presupuesto.

## ¿Qué permite hacer?

- Describir una aplicación y sus necesidades principales.
- Recibir propuestas de infraestructura asistidas por inteligencia artificial.
- Revisar y comparar alternativas y sus costes estimados.
- Preparar una contratación y consultar el seguimiento de un despliegue simulado.

La inteligencia artificial ayuda a elaborar recomendaciones; la decisión final corresponde a la persona usuaria.

## Alcance del proyecto

KeyDeploy se desarrolla como un proyecto académico para la asignatura **Desarrollo Web en Entorno Servidor (DSW)**, durante el curso 2026/2027. En esta versión, los pagos y los despliegues son simulados: no se realizan cobros ni se crean infraestructuras reales.
